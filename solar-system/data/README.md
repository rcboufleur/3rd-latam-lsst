# Offline fallback data

These files are loaded by `utils.py` or named explicitly in the notebook.

| File | Role |
| --- | --- |
| `occultations_sample.csv` | Pluto occultation snapshot used when the Solar System Portal is down |
| `mpc_orbits_sample.csv` | Small public orbit sample |
| `mpc_x05_count_sample.csv` | Measured Rubin (`stn='X05'`) count snapshot |
| `mpc_obs_sample_head.csv` | Small `X05` observation sample |
| `mpc_2026ED138_orbit.csv` | Orbit snapshot for `2026 ED138` |
| `mpc_2026ED138_obs.csv` | Observation snapshot for `2026 ED138` |
| `vesta_photometry.csv` | Synthetic Vesta light curve (period 5.342 h) |
| `eros_photometry.csv` | Synthetic Eros light curve (period 5.270 h) |
| `figures/` | Shadow map and light-curve PNGs used by the notebooks |
